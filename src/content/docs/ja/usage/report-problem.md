このページでは、RealTrainMod (RTM)の不具合や問題を報告する方法について説明します。
## 公式版RealTrainMod
公式版のRTMの不具合の報告は、開発者であるngt5179氏に直接行います。

過去には、[マインクラフト非公式日本ユーザーフォーラム](https://forum.minecraftuser.jp/)で開発状況の共有や、不具合の報告が行われていましたが、当該掲示板がサイバー攻撃によって閉鎖されてからは、公式なコミュニティは存在しないため、ngt5479氏に直接連絡するしかありません。
## KaizPatchX
KaizPatchXの不具合の報告は、[KaizPatchXのGitHub Issues](https://github.com/Kai-Z-JP/KaizPatchX/issues)で行います。

:::tip
[GitHub Issues](https://docs.github.com/ja/issues/tracking-your-work-with-issues/learning-about-issues/about-issues)で不具合を報告するには、[Issueを作成](https://docs.github.com/ja/issues/tracking-your-work-with-issues/using-issues/creating-an-issue)する必要があります。
ただし、作成する前に[Issueの検索](https://docs.github.com/ja/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests)を行い、類似のIssueがすでに存在していないかよく確認します。
:::
## fixRTM
fixRTMの不具合の報告は、[fixRTMのGitHub Issues](https://github.com/fixrtm/fixRTM/issues)または[fixRTM公式Discordサーバー](https://discord.gg/9VkuSAtpRQ)で行います。
