配布物には必ず説明書（Readme.txt）を同梱しましょう。

## Readmeに書くべきこと

- **パックの名前とバージョン**
  - 例: Yamada Tarou No Densha v1.0
- **作者名**
  - あなたの名前（ハンドルネーム）
- **内容物の説明**
  - どんな車両が入っているか
- **利用規約（ライセンス）**
  - 改造したり再配布したりして良いか？
  - SNSや動画などで使って良いか？
  - **重要:** 元になったモデルパック（MCTq_Base）のライセンスに従っているか確認してください。

### テンプレート

```text
Yamada Tarou No Densha v1.0
制作: 山田太郎

■概要
RTMチュートリアルで制作した、初めての改造車両です。
○○線の車両をイメージして色を変えました。

■内容物
- Tc
- T
- M
- Mc

■利用規約
- 改造・再配布: OK
- SNSや動画などで使用: OK
- 商用利用: NG

■クレジット
このパックは、水音車両様の「MinatoCommuterTrainQ」を改造して制作しました。
この場を借りてお礼申し上げます。
```
