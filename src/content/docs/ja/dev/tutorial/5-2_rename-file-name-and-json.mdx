まずは、ファイルやフォルダの名前を変えて、他の車両と被らないようにします。

## ファイル名とフォルダの変更
<Steps>

1. `my-modelpack`→`MCTq_Base`→`assets`→`minecraft`の順にフォルダをダブルクリックして開きます。
2. `models`フォルダの中にある`org_mct_q_n`フォルダの名前を、あなたのオリジナルの名前に変えます。
   この例では、`yamada_tarou_no_densha`とします。
   **注意:** 半角英数字とアンダースコア(`_`)、ハイフン(`-`)のみを使ってください。日本語やスペースはNGです。
3. 同様に、`textures`→`train`フォルダの中にある`org_mct_q_n`フォルダの名前も、同じ名前（`yamada_tarou_no_densha`）に変えます。
4. `json`フォルダのJSONファイルの名前も、同様に変更します
   この例では、以下のようになります。
   `ModelTrain_org_mct_q_n1_Mc.json`を`ModelTrain_yamada_tarou_no_densha1_Mc.json`に変更します。
   `ModelTrain_org_mct_q_n2_T.json`を`ModelTrain_yamada_tarou_no_densha_T.json`に変更します。
   `ModelTrain_org_mct_q_n3_M.json`を`ModelTrain_yamada_tarou_no_densha_M.json`に変更します。
   `ModelTrain_org_mct_q_n4_Tc.json`を`ModelTrain_yamada_tarou_no_densha_Tc.json`に変更します。
   :::caution
   `ModelTrain_`は、RTMの列車モデルであることを示すものなので、変更しないでください。
   :::
5. `sound_mctq_mi`フォルダの名前も、同様に変更します。
   この例では、`sound_mctq_mi`を`sound_yamada_tarou_no_densha`に変更します。
</Steps>

## trainNameとファイルパスの変更
JSONファイルを開き、trainNameとファイルパスをそれぞれ変更したフォルダ名に対応するように変更します。

変更例は以下の通りです。

これで、完全に独立した車両として認識されるようになりました！

:::tip[やってみよう]
同様に、他の車両のJSONファイルも編集して、全部の車両のtrainNameとファイルパスを変えてみましょう。
:::
