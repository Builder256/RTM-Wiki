モデルパックの改造を始める前に、モデルパックの構造について理解しましょう。

## モデルパックの構造
モデルパックは、主に4つのフォルダで構成されています。

<FileTree>

- MCTQ_Base (zipファイル)
  - assets
    - minecraft
      - **json/** 設定 JSONファイル
      - **models/** 形 MQOファイル
      - **textures/** 見た目 PNGファイル
    - **sound_mctq_mi/** 音 JavaScriptとOGGファイル

</FileTree>

それぞれのフォルダには、以下の役割があります。

1.  **json**: 車両の速度や加速力、座席の位置などを決めるファイルが入っています。
2.  **models**: 車両の3Dモデル（形）のデータが入っています。
3.  **textures**: 車両の色や模様（テクスチャ）の画像が入っています。
4.  **sound_mctq_mi**: 走行音やドアの開閉音などの音声ファイルが入っています。

このモデルパックでは、これら4つの要素が組み合わさって、1つの車両が構成されています。

:::tip[ポイント]
まずは「**json**」「**models**」「**textures**」「**sound_mctq_mi**」の4つがあることを覚えましょう！
:::

## 車両の種類
このモデルパックでは、4種類の車両が実装されています。

1. 制御動力車（クモハ）
   ファイル名には、「`Mc`」と含まれています。
   パンタグラフの付いている先頭車です。
2. 中間車（サハ）
   ファイル名には、「`T`」と含まれています。
   中間車です。
3. 動力車（モハ）
   ファイル名には、「`M`」と含まれています。
   パンタグラフの付いている中間車です。
4. 制御車（クハ）
   ファイル名には、「`Tc`」と含まれています。 
   先頭車です。

お気づきの方もいるかもしれませんが、`M`が動力車、`T`が付随車、`c`が制御車という意味になります。
