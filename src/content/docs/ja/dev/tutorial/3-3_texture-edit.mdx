ここからは、実際に改造を始めていきます。まずは一番簡単な「色変え」から始めましょう。

## 帯の色を変える
<Steps>
1. `my-modelpack`→`MCTq_Base`→`assets`→`minecraft`→`textures`→`train`→`org_mct_q_n`の順にフォルダをダブルクリックして、テクスチャのあるフォルダを開きます。
2. `mct_q_Tc.png`という画像ファイルを見つけます。これが車両の展開図（テクスチャ）です。
3. このファイルをGIMPで開きます。
   右クリック→「プログラムから開く」→「GIMP」をクリックします。
4. 画面左側のツールボックスから、「色域の選択」を選びます。
   ショートカットキーは、<kbd>Shift</kbd>+<kbd>O</kbd>です。
5. ツールオプションで「しきい値」を`0.0`に設定します。
6. 画像上部分の車体側面の部分にある、水色の帯の部分をクリックします。ドアや妻面にある帯の水色の部分も点線で囲まれます。
7. 描画色を好きな色（例えば赤色）に変更します。
8. メニューバーの「編集」→「描画色で塗りつぶす」をクリックします。
   水色だった部分の帯の色が変わったことを確認します。
9. メニューバーの「ファイル」→「mct_q_Tc.png に上書きエクスポート」をクリックして保存します。
   「保存」や「名前を付けて保存」ではないことに注意してください。
   「保存」は、GIMPの形式（XCF）で保存するためのもので、PNG形式で保存するには「エクスポート」をする必要があります。
</Steps>

これで、テクスチャの編集は完了です。

:::tip[やってみよう]
同様に、他の車両のテクスチャも編集して、全部の車両の帯の色を変えてみましょう。
:::
