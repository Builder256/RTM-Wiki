## 編集環境を用意する
モデルパックを編集するための専用のフォルダを用意して、改造をやりやすくします。
### デスクトップにモデルパック作成場所を用意する。
<Steps>
1. デスクトップにフォルダーを作り、「`my-modelpack`」という名前にします。
2. `mods`フォルダの`MCTq_Base.zip`を、`my-modelpack`にコピーします。
</Steps>
### モデルパックを展開する
<Steps>
1. `MCTq_Base.zip`を右クリックし、「すべて展開」をクリックします。
2. 「圧縮（ZIP 形式）フォルダーの展開」ウィンドウが開いたら、「展開」をクリックします。
   「完了時に展開されたファイルを表示する」の項目は、チェックを外してください。
3. `MCTq_Base`フォルダが作成されたら、`MCTq_Base.zip`は削除します。
   `MCTq_Base.zip`はもう不要です。
4. `MCTq_Base`フォルダを開き、`assets`フォルダと、`readme.txt`ファイルを確認します。
</Steps>
## 編集を始める
### 帯の色を変える
<Steps>
1. `assets/minecraft/textures/train/org_mct_q_n/`フォルダが作成されたら、中身を開きます。
2. `mct_q_Tc.png`ファイルをGIMPで開きます。
3. 左側のツールボックスから、「色域の選択」を選び、その下のメニューで「しきい値」を0.0に設定します。
4. 「アクティブな描画色」に赤色を設定します。
5. 水色の太い部分のどれかをクリックします。
6. 枠に点線が表示されたら、右クリックして開いたメニューを「編集」→「描画色で塗りつぶす」の順にクリックします。
   帯の色が赤色になりました。
7. メニューバーから、「ファイル」→「mct_q_Tc.png に上書きエクスポート」の順にクリックします。
   画面の一番下に、「画像は、○○として保存されました」と一瞬表示されます。
</Steps>
これで、帯の色を変えることができました。
:::tip
今回は帯の色を変えるだけでしたが、他の場所も変えれば自由な絵柄の電車にすることができます。
:::
