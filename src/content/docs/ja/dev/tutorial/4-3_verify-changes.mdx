## 変更を確認する

<Steps>
1. Minecraftを起動し、ワールドに入ります。
2. 先ほど設置した車両（または新しく設置した車両）を見てみましょう。
3. 帯の色が変わり、列車無線アンテナが消えていれば成功です！
</Steps>

自分で手を加えた車両がゲーム内で動く感動を味わってください！
