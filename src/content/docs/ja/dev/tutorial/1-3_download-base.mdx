## モデルパックのダウンロード
このチュートリアルでは、水音車両より公開されている、**MinatoCommuterTrainQ**を使用します。

MinatoCommuterTrainQのダウンロードは、uploader.jpから行います。

公式サイト：[MinatoCommuterTrainQ | Minato Car Corp.](https://minatocc.com/archives/3033)


<Steps>
1. 「基本セット」と記載されている場所の「ダウンロード」リンクをクリックし、uploader.jpのダウンロードページにアクセスします。
   また、「passの内容」も必要になるため、クリップボードにコピーしておきます。
2. ダウンロードページでは、uploader.jpの利用規約を確認したうえで、ダウンロードパスワードの入力欄にコピーした「passの内容」を入力して、「認証」ボタンをクリックしてください。
3. 認証が完了したら、ダウンロードが始まります。
4. しばらく待ってダウンロードが完了したら、わかりやすい場所（「ダウンロード」フォルダなど）に保存しておいてください。
</Steps>

:::note
本チュートリアルで使用する**MinatoCommuterTrainQ**は、非常に寛容なライセンスとわずかな改変で「改造」とみなされる柔軟性から、学習用途に最適です。
:::
