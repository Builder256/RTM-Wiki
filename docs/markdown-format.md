# Markdownのフォーマット
**例**
```markdown
---
label: ページのナビゲーションでの表示名
description: ページのmeta descriptionに使用される説明文
---
# タイトル（見出し1）
本文
## 章（見出し2）
本文
### さらに下位の章（見出し3）
本文
```
## フロントマター
原稿のMarkdownには、以下のプロパティを持つYAML形式のフロントマターを含めることができる
- `label`: そのページがメインメニューのナビゲーションで表示されるときの表示名
- `description`: HTMLの`meta description`に使用される説明文
### 例
```yaml
label: ページの表示名
description: ページの説明
```
## 本文
本文はMarkdownで記述する。本文の一番最初に、見出し1を使用してページのタイトルを記述しなければならない。  
見出し1はタイトルの一つのみで、その他の見出しは最大でもレベル2のものにしなければならない。
